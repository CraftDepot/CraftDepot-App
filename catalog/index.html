CraftDepot catalog

Open-source Rust replacements for paid software, and the launcher that installs them. Launchers read the catalog from this address.

Install CraftDepot

Windows (PowerShell)
irm https://craftdepot.github.io/CraftDepot-App/install.ps1 | iex
macOS and Linux
curl -fsSL https://craftdepot.github.io/CraftDepot-App/install.sh | sh

Or download an installer: Windows, Windows on Arm, macOS.
